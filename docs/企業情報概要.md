## 2. 事業と収益モデル

主力サービス「CloudDesk」は、社内問い合わせと業務申請を一元化する法人向けSaaS。利用人数に応じた月額課金を基本とし、導入支援・設定・データ移行・運用保守も提供する。

| 事業 | 提供内容 | 収益源 |
| --- | --- | --- |
| 自社SaaS | CloudDeskの利用提供 | ユーザー数に応じた月額課金 |
| 導入・改善支援 | 業務整理、初期設定、移行支援 | 案件ごとの導入費用 |
| 運用・保守 | 問い合わせ・保守・追加設定 | 継続サポート契約 |

| CloudDeskプラン | 2026年1月以降の月額単価 |
| --- | --- |
| Basic | 1,800円／人 |
| Pro | 2,900円／人 |
